ABOUT THIS PLATFORM

I built CloudAtlas to make troubleshooting explainable.

Support work becomes risky when symptoms live in tickets, commands live in terminals, and recovery knowledge lives only in someone’s memory. CloudAtlas creates one operating story: impact, evidence, diagnosis, escalation, change, validation, and closure.

The product pairs a FastAPI and SQLite service with an enterprise browser workspace. I used typed validation, auditable events, priority-based SLA targets, and explicit recovery evidence so each decision can be reviewed.

This is a working portfolio implementation with 30 seeded practice cases and 18 runbooks. A production deployment would add identity-aware access, PostgreSQL, migrations, background notifications, tenant isolation, and an observability backend.
